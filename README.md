# نِظام كونكت (Nidham Connect)

برنامج ويندوز صغير بيحل أكبر مشكلة تفعيل في نِظام: **ربط جهاز البصمة**.

## ليه الاتجاه ده؟

طريقة ADMS/Cloud Server (الجهاز يبعت بنفسه) فشلت ميدانيًا: القايمة مش موجودة
في أغلب الأجهزة المنتشرة في السوق، وضبطها فوق طاقة العميل. نِظام كونكت بيقلب
الاتجاه — زي برنامج ZKTime/Attendance Management اللي العملاء متعودين عليه:

- البرنامج على كمبيوتر الـHR **هو اللي بيكلم الجهاز** على الشبكة المحلية
  (بروتوكول TCP 4370 الموجود في كل أجهزة ZKTeco وأشباهها حتى القديمة جدًا).
- وبعدين بيرفع البصمات لـنِظام على HTTPS — يعني NAT-proof: مفيش port
  forwarding ولا إعدادات راوتر ولا قوايم جهاز خالص.

## تجربة العميل

1. من صفحة «ربط أجهزة البصمة» في نِظام: نزّل البرنامج + اعمل كود ربط.
2. اكتب الكود في البرنامج (مرة واحدة).
3. دوس «دوّر في الشبكة» — البرنامج بيلاقي الجهاز لوحده ويبدأ يزامن كل 3 دقايق.

رقم الموظف على الجهاز (Enroll ID) لازم يساوي «كود الموظف» في نِظام — وأي
أرقام مش متطابقة بتظهر بالاسم في البرنامج وفي صفحة الأجهزة عشان الـHR يصلّحها.

## المعمارية

| ملف | دوره |
|---|---|
| `main.js` | Electron main: نافذة + tray + حلقة المزامنة + IPC + تحديث تلقائي |
| `zk-device.js` | قراءة الجهاز عبر `zkteco-js` (سيريال/مستخدمين/بصمات) + كشف Comm Key |
| `sync.js` | نافذة الكيرسور + التقطيع + POST لـ`/api/device-agent/sync` |
| `scan.js` | مسح الشبكات الخاصة المحلية على بورت 4370 |
| `config.js` | تخزين الإعدادات atomically في `%APPDATA%/nidham-connect` |
| `renderer/` | الواجهة (عربي RTL، فانيلا) |
| `test/zk-sim.js` | **محاكي جهاز كامل** بنفس بايتات البروتوكول |
| `test/e2e.mjs` | اختبار الحلقة كلها بدون هاردوير: محاكي → قارئ → مزامنة → سيرفر وهمي |

السيرفر المقابل في الريبو الرئيسي: `nidham/src/app/api/device-agent/{pair,sync}`
والاستيعاب المشترك في `nidham/src/lib/zk-ingest.ts` (نفس عقل قناة ADMS بالظبط).

## أوامر

```powershell
npm start          # تشغيل تطويري
npm run e2e        # الاختبار الكامل ضد المحاكي (لازم يعدي قبل أي إصدار)
.\release.ps1      # bump + e2e + build + نشر على GitHub Releases (تحديث تلقائي للعملاء)
```

التنزيل الثابت (مربوط في صفحة الأجهزة):
`https://github.com/basemazab/nidham-connect/releases/latest/download/Nidham-Connect-Setup.exe`

## ملاحظات صيانة

- **Comm Key**: المكتبة مش بتدعم CMD_AUTH — لو الجهاز محمي بنكشفها
  (CMD_ACK_UNAUTH) ونطلب من العميل يخليها 0. لو ظهر طلب حقيقي كتير عليها،
  تتنفذ خوارزمية make_commkey (موثقة في spec بروتوكول zk).
- **أجهزة UDP القديمة**: المكتبة بتقع على UDP تلقائيًا لو TCP اترفض.
- البرنامج **عمره ما يمسح** سجلات من الجهاز (مفيش CMD_CLEAR_ATTLOG) —
  القراءة idempotent والسيرفر بيدمج.
- winCodeSign gotcha بتاع electron-builder على الويندوز: نفس الحل الموثق في
  `desktop/README` (فك الأرشيف يدويًا في كاش electron-builder).
